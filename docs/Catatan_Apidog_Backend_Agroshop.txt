CATATAN APIDOG BACKEND AGROSHOP
================================

Base URL:
http://localhost:3000

Base URL lewat gateway:
http://localhost:3003/api

Catatan gateway:
- Backend utama tetap berjalan di port 3000.
- Gateway berjalan di port 3003.
- Kalau lewat gateway, endpoint tetap sama tetapi diawali /api.
- Contoh:
  Backend langsung: http://localhost:3000/products
  Lewat gateway:    http://localhost:3003/api/products

Header umum:
Content-Type: application/json

Header untuk endpoint yang butuh login:
Authorization: Bearer TOKEN_DARI_LOGIN

Catatan:
- Setelah login, copy nilai "token" dari response.
- Tempel token tersebut ke header Authorization.
- Formatnya harus: Bearer spasi token
- Contoh:
  Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI...
- Panduan penggunaan CMS ada di:
  docs/Panduan_CMS_Agroshop.txt


1. REGISTER USER / ADMIN
------------------------
Method:
POST

Endpoint:
/auth/register

Body contoh admin:
{
  "name": "Admin Agroshop",
  "email": "admin@agroshop.test",
  "password": "admin123",
  "phone": "081234567890",
  "imageUrl": "https://picsum.photos/seed/admin/200/200",
  "address": "Jl. Pertanian No. 1"
}

Body contoh user pembeli:
{
  "name": "Budi Petani",
  "email": "budi@agroshop.test",
  "password": "budi123",
  "phone": "081111111111",
  "imageUrl": "https://picsum.photos/seed/budi/200/200",
  "address": "Jl. Sawah No. 10"
}

Catatan:
- Register default role-nya FARMER.
- Kalau ingin menjadikan admin, ubah role user lewat Prisma Studio menjadi ADMIN.
- Buka Prisma Studio:
  npx prisma studio


2. LOGIN
--------
Method:
POST

Endpoint:
/auth/login

Body admin:
{
  "email": "admin@agroshop.test",
  "password": "admin123"
}

Body user:
{
  "email": "budi@agroshop.test",
  "password": "budi123"
}

Response penting:
- Ambil "token"
- Ambil juga data "user"

26. CHECKOUT / CREATE ORDER
---------------------------
Butuh token user.

Method:
POST

Endpoint:
/orders/checkout

Body contoh:
{
  "address": "Jl. Sawah No. 10, Bandung"
}

Body contoh pakai alamat yang sudah disimpan:
{
  "addressId": 1
}

Catatan:
- Sebelum checkout, cart harus berisi produk.
- addressId adalah ID dari GET /addresses.
- Setelah checkout berhasil, cart user akan dikosongkan.
- Pesanan akan masuk ke riwayat order.
- Data pengiriman awal akan otomatis dibuat.
